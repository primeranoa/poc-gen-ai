# 05 — batchUpdate.xml

**Job Name:** `UPDATE`  
**Tipo:** SQL (MERGE / upsert)  
**Transazionale:** Si

## Scopo

Trasferisce i dati validati dalle tabelle TMP_* alle tabelle definitive PPE*/PAA*, usando operazioni MERGE.

## Operazioni principali

| # | Source | Target | Chiave MERGE | Condizione |
|---|--------|--------|--------------|------------|
| 0 | TMP_ANAGRTIT | PPECATALOGO | CODICE_ISIN = CODICE_TITOLO | Sempre |
| 1 | TMP_PPEESG_INSTR_ATTRIBUTES | PPEESG_INSTR_ATTRIBUTES | INSTRUMENT_CODE + PILLAR_KEY | BATCH_ENABLE_TASK_ESG |
| 2 | TMP_CATALOGOTM | PPECATALOGOTM | CODICERISCHIO + TIPOCONTROLLO + DOMINIO | Sempre |
| 3 | TMP_SETUPTM | PPESETUPTM | CODICEBANCA + TIPOCONTROLLO + ESITO | Sempre |
| 4 | TMP_FATTISPECIETM | PPEFATTISPECIETM | RAGGRUPPAMENTO + TIPOCONTROLLO + DOMINIO | Sempre |
| 5 | TMP_COSTI_STD_PRODOTTO | PPECOSTI | CODICEINTERNO + CODICECOSTO + scaglioni | Sempre |
| 6 | TMP_COSTI_STD_FATTISPECIE | PPECOSTIFATTISPECIE | CODICERAGGRUPPAMENTO + CODICECOSTO + scaglioni | Sempre |
| 7 | TMP_PAAMAPPATURA | PAAMAPPATURA | CODICETITOLO + CODICE | BATCH_ENABLE_TASK_MAPPATURA |
| 8 | TMP_PAAMAPPATURAVALUTARIA | PAAMAPPATURAVALUTARIA | CODICETITOLO + CODICE | BATCH_ENABLE_TASK_MAPPATURAVALUTARIA |

| 10 | TMP_PPEPRAPROXY | PPEPRAPROXY | CODICE_TITOLO | BATCH_ENABLE_TASK_IMPORT_PRAPROXY |
| 11 | TMP_PPESTRUMCOEFF | PPESTRUMCOEFF | C_INSTRUMENT + C_CONTROLLO | BATCH_ENABLE_TASK_ANASTRUMCOEFFICIENTI |

## Logica Task 0 (Update Catalogo)

1. `UPDATE PPECATALOGO SET STATO = 'S'` — tutti sospesi
2. `INSERT ... ON CONFLICT DO UPDATE` — upsert con STATO='A' per presenti nel flusso
3. Riattivazione prodotti fittizi
4. Update BKD_ESG = IS_ESG_APPLICABLE
5. Update DECODE_CANALE
